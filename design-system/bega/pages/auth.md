# Authentication Profile

**Intent:** Help users sign in, register, recover access, and understand validation or provider errors.

- Prioritize readable labels, field-level feedback, keyboard operation, and focus visibility.
- Keep the current BEGA auth components and tokens. Pro Max's navy/gold palette and Lexend pairing are unadopted.
- Density 4, motion 1, variance 3 are search dials only. Avoid motion that delays form feedback.
- Preserve responsive layouts, accessible authentication, and clear recovery paths.
- Representative harness component: `src/components/Login.tsx#Login`.
